# 経済指標

世界各国の経済指標・統計データを更新頻度別に自動集約するツール。

## データソース

| ソース | データ内容 | 更新頻度 | APIキー |
|--------|-----------|---------|---------|
| World Bank API | GDP、人口、インフレ率、失業率等 | 年次 | 不要 |
| IMF API | 国際収支、為替、財政指標 | 四半期〜年次 | 不要 |
| ECB SDMX API | ユーロ圏金利、為替レート | 日次〜月次 | 不要 |

## 使い方

```bash
cd 経済指標
npm install
npm run collect    # データ収集・集約
npm test           # テスト実行
```

## 出力

`output/` に更新頻度別のJSONファイルが生成される:

- `日次指標.json`
- `月次指標.json`
- `四半期指標.json`
- `年次指標.json`
