#### データ統合ロジック（`thShowSub`）

サブテーマ選択時、4つのJSONから**キーワードマッチング**で関連データを自動収集して表示：

| ブロック | データソース | マッチング方法 |
|---------|-------------|--------------|
| 📰 関連ニュース | `all.json` | タイトル・タグ・背景・最新フィールドにキーワード含む |
| 📊 シェア・統計 | `market_share.json` | 製品カテゴリー名にキーワード含む |
| 📚 用語集 | `glossary.json` | 用語名・英語名・説明にキーワード含む |
| 🧠 背景知識 | `knowledge.json` | タイトル・概要・現状にキーワード含む or 同カテゴリー |

各ブロックはアコーディオンで開閉可能。デフォルトはニュース・統計が展開済み。
