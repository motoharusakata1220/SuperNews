## 1. 全体コンセプト

**「サブテーマ（素材・製品）粒度で全データが統合表示される情報ブラウザ」**

```
エネルギー > 水素  →  ニュース + シェア統計 + 用語 + 背景知識 が一画面に
エネルギー > ヘリウム  →  同上
半導体 > シリコンウエハー →  同上
```

データはバラバラのJSONに入っているが、**テーマブラウザ**がキーワードマッチで横断的に統合して表示する。

### 4-3. データ統合ロジック

```javascript
// サブテーマ選択時の処理フロー
thShowSub(catName, subName)
  ↓

  ↓
// all.json: タイトル・タグ・背景・最新 にキーワード含む記事を抽出
// market_share.json: 製品カテゴリー名にキーワード含む品目を抽出
// glossary.json: 用語名・英語・説明にキーワード含む語を抽出
```

### アコーディオン

```javascript
function toggleAcc(hd) {
  const bd = hd.nextElementSibling;  // .acc-bd は必ず .acc-hd の直後に置く
  const isOpen = hd.classList.contains('open');
  hd.classList.toggle('open', !isOpen);

}
```

## 8. 開発ルール

### HTML構造ルール

- `<div>` の開閉バランスを常に確認する
  ```python
  # 確認コマンド
  python3 -c "
  from html.parser import HTMLParser
  class T(HTMLParser):
      d=0
      def handle_starttag(s,t,a):
          if t=='div': s.d+=1
      def handle_endtag(s,t):
          if t=='div': s.d-=1
  with open('docs/dashboard.html') as f: c=f.read()
  t=T(); t.feed(c); print('depth:', t.d)  # 0なら正常
  "
  ```

### JavaScript構文ルール

- `{` `}` のバランスを確認する
  ```python
  python3 -c "
  import re
  with open('docs/dashboard.html') as f: c=f.read()
  s=re.findall(r'<script>(.*?)</script>',c,re.DOTALL)[0]
  print('diff:', s.count('{') - s.count('}'))  # 0なら正常
  "
  ```

### データ追加ルール

新しいニュース記事を `all.json` に追加する際は：
```json
{
  "id": "unique-id",
  "カテゴリ": "エネルギー",
  "サブカテゴリー": "水素・アンモニア",
  "タイトル": "...",
  "タグ": ["水素", "グリーン水素", "..."],
  "背景": "200字以内の背景",
  "最新": "500字以内の最新動向",
  "情報源": "https://...",
  "収集日": "2026-04-19"
}
```

テーマブラウザのキーワードマッチが `タグ`・`サブカテゴリー`・`タイトル`・`背景`・`最新` を対象にしているため、**`タグ` と `サブカテゴリー` の設定が最も重要**。

### Git操作ルール

- `git push` は坂田さんの明示的な許可が必要
- `git add` / `git commit` はローカルのみ可
- コミットメッセージ形式: `feat:` / `fix:` / `refactor:` / `docs:`

## 9. 今後の拡張方針

### 優先度高

1. **データ充実**: ニュース記事のサブカテゴリー・タグを正確に設定する（テーマブラウザの精度向上）
2. **knowledge.jsonエントリ追加**: 中要素・事象レベルのデータを充実させる
3. **market_share.json品目拡充**: COLLECTION_PLAN.mdに記載の品目を追加

### 優先度中

4. **サプライチェーン図**: テーマブラウザに「上流→中流→下流」の構造図を追加（knowledge.jsonに`サプライチェーン`フィールドが必要）
5. **カテゴリーサイドバーの折りたたみ**: 現在全展開のサイドバーをカテゴリー単位で折りたためるようにする
6. **企業プロファイル連携**: テーマブラウザに関連企業ブロック（5つ目）を追加

### 優先度低

7. **動画生成**: Claude Code + 外部ツールで自動動画生成
8. **RSS収集自動化**: VPSでcronを設定して日次収集
