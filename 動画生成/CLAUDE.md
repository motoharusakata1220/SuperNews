# 動画生成カテゴリ

## 概要
全カテゴリ（投資・世界情勢・企業情報・経済指標・背景知識）の情報を元に、
YouTube動画をAIで自動生成するシステム。

## 4つのフレームワーク

### 1. 市場ニッチ分析
- CPM率が高いニッチの特定
- 年齢・興味に基づくマッチング
- 競争分析と収入予測

### 2. 顔なしビデオシステム
- SEO最適化されたタイトル
- カメラ不要の完全台本
- ナレーション指示・アーカイブ映像キーワード
- サムネイルコンセプト

### 3. バイラルタイトルジェネレーター
- 好奇心・数字・恐怖/緊急性・変革の4カテゴリ
- CTR予測・感情分析・SEOキーワード強度

### 4. AI自動化ワークフロー
- $0予算の無料AIツール活用
- 脚本→ナレーション→編集→サムネイルのワークフロー
- バッチ生産・アップロードカレンダー
- 複数チャンネル同時管理

## 使い方
```bash
cd src/generators
npx ts-node pipeline.ts
```

## 出力先
- 台本: `動画生成/台本/`
- 分析結果: `動画生成/分析結果/`
- 最終成果物: `output/動画/`
