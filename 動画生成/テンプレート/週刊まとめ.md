# 週刊まとめ型テンプレート

## 動画構成（15-20分想定）

### 1. オープニング（0:00-0:30）
- 「今週、見逃してはいけない○つのニュースをまとめました」
- 今週のハイライトを3秒ずつ見せる

### 2. ニュース #1 — 最重要（0:30-4:00）
- 最もインパクトのあるニュースから開始
- 詳細な解説 + 背景情報
- SuperNewsの独自分析（関係性データ活用）

### 3. ニュース #2-3 — 重要（4:00-8:00）
- 各2分程度で解説
- 相互の関連性を示す（関係性グラフ活用）

### 4. パターン中断 — 意外なニュース（8:00-9:00）
- 「ここで、ほとんどの人が見逃しているニュースがあります」
- ニッチ情報の真骨頂

### 5. ニュース #4-5 — 注目（9:00-13:00）
- トレンド系・テクノロジー系
- 将来への影響を分析

### 6. 今週の結論 + 来週の予測（13:00-15:00）
- 全ニュースの関連性を総括
- 来週注目すべきポイント
- CTA: 「来週もお見逃しなく」

## カテゴリ横断の視点
- 投資 × 世界情勢 → 市場への影響
- 企業情報 × 経済指標 → 業績予測
- 背景知識 → 深い理解のための文脈

## 映像指示
- ニュース映像: Pexels, Pixabay
- チャート: TradingView (スクリーンショット)
- 関係図: Canva無料版で作成

## バッチ生産のコツ
- 毎週日曜にデータ収集・台本作成
- 月曜に撮影・編集
- 火曜にアップロード + Shorts切り出し
