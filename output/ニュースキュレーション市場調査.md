# ニュースキュレーション・情報収集ダッシュボード市場調査

> 作成日: 2026-04-05
> 目的: 人気サービスの「売れるロジック・仕組み」分析（SuperNews設計の参考資料）

---

## カテゴリ1: ニュースアグリゲーター

### 1. Feedly

| 項目 | 内容 |
|------|------|
| 概要 | RSS/AIベースのコンテンツ収集・整理プラットフォーム。個人〜企業向けにマーケットインテリジェンス機能まで展開 |
| 収益モデル | フリーミアム（無料プラン + Pro/Pro+/Business）+ エンタープライズ向けB2Bサブスク |
| 規模 | 登録ユーザー1,400万人以上（2018年時点）。企業向けMarket Intelligenceは月額$1,600〜 |
| 差別化ポイント | AI「Leo」による要約・フィルタリング。サイバーセキュリティ・競合情報収集など業務用途への深化 |
| 引きつける仕組み | RSSという枯れた技術をAIで再解釈。フィードのノイズを除去し「読むべき記事だけ」に絞る体験 |
| 参考パターン | **水平→垂直展開**: 汎用RSSリーダーから始め、法人向けインテリジェンスツールへと価値を引き上げ単価を1,000倍以上に |

### 3. Google News

| 項目 | 内容 |

## カテゴリ2: ソーシャルキュレーション

### 6. Reddit

| 項目 | 内容 |
|------|------|

| 参考パターン | **コミュニティ資産**: コンテンツを外部から集めず、ユーザー自身に生成させる。モデレーターは無給の「自発的管理者」 |

## 横断分析: 売れるロジック・共通パターン

### パターン1: フリーミアムの設計精度

| 成功要因 | 具体例 |
|----------|--------|
| 無料版で「味を知らせる」 | Feedly無料→Pro有料変換、Substack無料→有料転換 |
| 課金のトリガーが明確 | 「無料だと〇フィードまで」「スポンサーなし体験」 |
| ペイウォールが苦にならない価値 | The Information $399/年でも払う読者が存在 |

### パターン2: コミュニティ×情報の合体

| 成功要因 | 具体例 |
|----------|--------|
| 情報への解釈・議論を付加 | NewsPicks（専門家コメント）、Reddit（スレ議論） |
| 投稿・評価で参加感を演出 | Hacker News（karma）、Product Hunt（投票） |
| コミュニティが情報の質を担保 | HNモデレーション、Redditサブレ自治 |

### パターン3: 時間節約の価値化

| 成功要因 | 具体例 |
|----------|--------|
| 「読む時間」の削減を売る | Morning Brew（5分）、TLDR（5分）、Axios（Smart Brevity） |
| 情報過多時代のフィルタリング | Feedly Leo AI、Google News AI |
| 要約精度が差別化要因 | 各ニュースレターが独自フォーマットを確立 |

### パターン4: 特定ペルソナへの最適化

| 成功要因 | 具体例 |
|----------|--------|
| 年齢・職種・趣味の絞り込み | TheSkimm（女性ミレニアル）、TLDR（エンジニア）、The Information（シリコンバレー投資家） |
| 言葉遣い・文体の統一 | Morning Brew（軽快）、The Information（硬派） |
| 広告単価の最大化 | ニッチ×高購買力層で広告CPMが高騰 |

### パターン5: 直接課金への移行

| 成功要因 | 具体例 |
|----------|--------|
| 広告依存脱却でユーザー利益と一致 | Substack、The Information |
| 読者との直接関係（メール/アプリ） | アルゴリズム依存ゼロのメール配信 |
| 購読収益の安定性がコンテンツ投資を可能に | Morning Brew、Axios |

## SuperNewsへの応用示唆

1. **ニッチ特化が正義**: 「全ジャンル」より「○○専門」の方が差別化・広告単価ともに有利
2. **コメント・解釈レイヤーを追加**: ニュース本体より「誰がどう読むか」に価値がある（NewsPicks型）
3. **要約＋ソース付きが信頼の源泉**: TLDRのように「短くても引用元リンクあり」が信頼を生む
4. **メール配信の直接性**: アルゴリズムに左右されないメール/プッシュが最強の接点
5. **動画化の優位点**: テキストキュレーション市場は飽和気味。動画要約（YouTube Shorts等）は未開拓ブルーオーシャン
