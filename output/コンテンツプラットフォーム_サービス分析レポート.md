## カテゴリ1: コンテンツ自動生成・キュレーション

### 1. Curata（コンテンツマーケティングプラットフォーム）

| 項目 | 内容 |
|------|------|
| **概要** | AIを活用してWebコンテンツを自動収集・分類・スコアリングし、ブランドのコンテンツパイプラインを構築するB2Bプラットフォーム |
| **収益モデル** | エンタープライズ向けサブスクリプション（カスタム価格・年次契約） |
| **規模** | コンテンツキュレーションソフト市場全体: 7億8,040万ドル（2025年）→ 24億8,940万ドル（2035年予測） |
| **差別化ポイント** | 「コンテンツサプライチェーン」の概念を提唱。単なるキュレーションでなく、Content Marketing Platform（CMP）とContent Curation Software（CCS）の2軸でROI可視化まで担う |
| **引きつける仕組み** | コンテンツのパフォーマンス分析→次の配信戦略へのループ。データドリブンで「何を作るべきか」を提案 |
| **法則・パターン** | **ROI可視化の法則**: 成果が見えると継続率が上がる。B2B SaaSでの鉄板パターン |

## 横断分析: 「売れる」共通パターン TOP7

### パターン1: フリーミアムの最適設計
無料版で価値を実感させ、壁を作って有料転換。**鍵は「無料で十分使えるが、有料なら圧倒的に便利」という絶妙なバランス**。Feedly・Brand24・Inoreaderが典型例。

### パターン2: AI×パーソナライゼーションのロックイン
使えば使うほど賢くなるAIが「乗り換えコスト」を自動的に高める。データの蓄積 = 競合優位性。TikTok・Feedly Leo・Spotifyが代表例。

### パターン3: 習慣インフラ化
通勤・通勤・睡眠などの生活シーンに組み込まれた瞬間に「解約検討」が発生しにくくなる。Spotify・Voicy・Yahoo!ニュースが該当。

### パターン4: プラットフォーム統合による粘着性
複数ツールを1つに統合した瞬間にスイッチングコストが急上昇。ContentStudio・Talkwalker（Hootsuite統合）・Mention（Agorapulse統合）が代表。

### パターン5: 危機回避の恐怖訴求
「見逃したら損失が出る」「炎上を検知できなかった」というネガティブな動機が継続課金を支える。Brand24・Google Alertsが典型例。

### パターン6: クリエイターエコノミーの両輪
クリエイターへの収益分配 → コンテンツ量と質の向上 → ユーザー獲得 → 広告・サブスク収益増加の好循環。Spotify・stand.fm・YouTube Shortsが該当。

### パターン7: ニッチ特化による熱狂ユーザー獲得
万人向けではなく特定の価値観・スキルレベルのユーザーに深刺しすることで「これしかない」ポジションを確立。Miniflux（ミニマリスト）・NewsBlur（プライバシー重視）・Inoreader（パワーユーザー）が典型例。

## SuperNews開発への示唆

1. **AI要約×フィルタリング機能**は今や必須差別化ポイント（Feedly Leoが証明）
2. **ニッチ情報の発見性**こそが既存大手との差別化軸（Google Alertsでは拾えないニッチ情報）
3. **動画＋音声の複合生成**でTikTok/Voicy/stand.fmの複数チャンネル同時展開が理想
4. **アラート機能**を組み込むことでユーザーの日常業務に組み込み、チャーン防止が可能
5. **コンテンツキュレーション→動画生成**の自動パイプラインが他サービスにない独自価値になりうる
