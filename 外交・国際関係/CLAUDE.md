# SuperNews — 外交・国際関係 エージェント

親フォルダの CLAUDE.md ルールをすべて継承する。

## 担当領域

国際機構・地域統合・制裁・首脳外交・二国間関係を収集・構造化する。

## 調査するサブ項目（タグ一覧）

- 国連安保理・総会
- WTO・貿易紛争
- IMF・世界銀行
- OECD・BIS
- EU（拡大・離脱・制度改革）
- ASEAN・RCEP
- BRICS（拡大・脱ドル）
- G7・G20・サミット
- アラブ連盟・アフリカ連合
- 米国制裁（OFAC）
- EU制裁
- 国連制裁決議
- 米中関係
- 米ロ関係
- 日中・日韓関係
- 中露関係
- 中東外交（サウジ・イラン・イスラエル）
- 首脳会談・国際会議
- 国際条約・協定締結
- 外交的追放・大使召還

## 毎回実行するフロー

1. **ソース確認**: `ソース/有効.json` を読み込み既存ソースを把握する
2. **最新情報収集**: 各ソースから外交・国際関係に関する最新情報を収集する
3. **新ソース探索**: サブ項目に関連する良質な情報源を横断的にリサーチする
4. **ソース評価**: 鮮度・客観性・ファクトチェック通過を評価し `ソース/評価履歴.json` に記録する
5. **生データ保存**: 収集した生情報を `生データ/` に保存する
6. **細分化タグ付け**: 各情報に上記サブ項目タグを複数付与する
7. **差分検出**: `../背景知識/出力/背景知識マスター.json` と照合し重複をスキップする
8. **関係性推論**: この情報が影響する他カテゴリ・関連企業・関連指標をAIが毎回推論する
9. **AI要約生成**: 下記スキーマに従い要約を生成する
10. **出力保存**: `出力/YYYY-MM-DD.json` に保存する

```json
{
  "カテゴリ": "外交・国際関係",
  "更新日時": "2026-04-11T10:00:00Z",

  ]

```

## ルール

- 書き込みは自分の `出力/` フォルダのみ。`../背景知識/` と `../関係性/` は読み取り専用
- 関係性への書き込みは hub ウィンドウが集約する
