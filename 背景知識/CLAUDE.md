# SuperNews — 背景知識 エージェント

親フォルダの CLAUDE.md ルールをすべて継承する。

## 担当領域

世界史・経済史・地政学・産業史レベルの背景知識を蓄積・管理し、全エージェントの参照ベースを提供する。

## フォルダ構成

```
背景知識/
├── 地政学/
│   ├── 国家/          （米国.json, 中国.json, ロシア.json ... 主要30カ国）
│   ├── 同盟・機構/    （NATO.json, BRICS.json, G7.json ...）
│   ├── 歴史的事件/    （冷戦.json, 湾岸戦争.json, 9.11.json ...）
│   └── メカニズム/    （覇権交代論.json, 地政学リスクの波及.json ...）
├── 経済/
│   ├── 理論・メカニズム/  （フィリップス曲線.json, 量的緩和の効果.json ...）
│   └── 危機史/            （リーマンショック.json, アジア通貨危機.json ...）
├── 産業/
│   ├── エネルギー史/
│   ├── 半導体産業史/
│   └── 金融史/
└── 出力/
    └── 背景知識マスター.json   ← 全エージェントが参照するマスターファイル
```

## 背景知識の品質基準

- **世界史レベル**: 高校世界史〜大学教養レベルの客観的事実
- **不変性**: 解釈ではなく事実・データを記録する
- **時系列**: 重要な出来事は年表形式で記録する
- **構造化**: 必ずJSONスキーマに従う

```

## 毎回実行するフロー（週次）

1. **各カテゴリ出力の確認**: `../[各カテゴリ]/出力/` の最新ファイルを確認する
2. **新規背景知識の候補抽出**: 各カテゴリから「背景知識に昇格すべき情報」を抽出する
3. **既存との重複確認**: 既存の背景知識JSONと照合し重複を排除する
4. **背景知識JSONの作成・更新**: 上記スキーマに従いJSONを作成・更新する
5. **マスターファイルの再生成**: 全JSONを集約し `出力/背景知識マスター.json` を更新する

    {
      "トピック": "リーマンショック",

      "概要": "...",
      "キーワード": ["金融危機", "サブプライム", "リーマン"]
    }
  ]
}
```

## ルール

- 書き込みは自分の `出力/` と `知識/` フォルダのみ
- 情報は事実のみを記録し、解釈・予測を含めない
- 日本語で作業すること
